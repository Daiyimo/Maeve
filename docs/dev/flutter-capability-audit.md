## 逐项处理

| 入口/状态 | 当前实现证据 | 处理 |
| --- | --- | --- |
| 高中低、内置 Maeve 引擎 | 控制器字段，无原生方法 | 删除；真实模型名来自 ProviderStore |
| 本机账号、登录同步、账单/套餐/余额/兑换码 | AccountPage 弹提示或固定文本 | 删除整页与身份卡入口 |
| 远程主机、插件市场、网页版、终端 | 显示壳/回显/接桥提示 | 删除 Flutter 页面和工作台入口；保留原生真实能力 |
| 本地 Flutter 记忆、运行记录 | 内存列表或静态说明 | 删除原型页；不触碰核心真实记忆与运行存储 |
| 语音、通知偏好、回复偏好、人格、语言 | 只改 MaevePrefs 或弹提示 | 删除未消费设置和页面 |
| 手机总开关、读屏测试、解除保护、清日志 | 本地布尔值或固定成功提示 | 删除假控制；系统授权改读 Android 实际状态 |
| 登录式首次引导/密钥 | 密钥只留内存且宣称内置引擎 | 删除；配置入口直接使用原生模型存储 |
| 附件/系统分享 | 仅弹接桥提示 | 删除按钮；保留真实文本复制与引用 |
| 自动同意 | 只改 Flutter 标志，无原生授权动作 | 删除按钮与状态 |
| 归档/恢复、未读计数 | 仅进程内隐藏，没有宿主持久化 | 删除；保留原生置顶/删除与真实会话检索 |
| 主题、配色、触感、透明降级 | 有真实视觉/触感消费者 | 保留，持久化 UI 偏好；移除未使用图标风格与低端机开关 |
| 模型配置 | 原生有持久化存储，但 Flutter 未接 | 保留必要配置，接回 ProviderStore；不伪造在线/测试成功 |
| 系统授权 | Android 支持真实查询和设置 Intent | 保留实际状态、系统授权入口及原生配对通知流程 |
| 关于/许可 | 原生打包文本与法律数据已接通 | 保留；移除虚假版本/更新结论 |
| 聊天、发送、停止、引用、会话、置顶、删除 | maeve/chat 已接 ChatViewModel/ConversationStore/TaskService | 保留并回归测试 |

不删除原生已存在的远程任务、MCP、浏览器、语音、记忆与安全门禁。删除的是没有连接它们的 Flutter 原型入口，不能用「无 UI」推断「无能力」。

## 模型持久化细节

`ProviderStore` 会清理没有用途引用的 `ProviderConfig`。因此 Flutter 列表使用原生 `ModelOptions.ofProvider` 的服务商模型信息，选择键由服务商和模型共同决定，不使用会被清理的配置 ID。新增接入调用 `connect(typed, untested = true)`，再由 `use(Main)` 选择；保留原生的加密密钥、手填模型记录、能力推导和未测试状态。切换后旧模型仍可选，重启也能恢复；不伪造在线状态或试调用结果。

真实主模型/看图/轻量用途仍由原生执行体系管理；本轮 Flutter 仅提供主模型接入与切换，不把用途包装为高中低套餐。既有原生账号授权能力也不等于被移除的虚构「本机账号」。
