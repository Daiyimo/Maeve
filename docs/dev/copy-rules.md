# 界面文案规范

界面上的字只做一件事：让人知道**现在是什么状态**、**按下去会发生什么**。
凡是做不到这两件事的字，都是在给自己的界面加噪音。

## 一、标题不要配复述它的副标题

```
✗ 手机操作
   设置后 Maeve 才能操作手机 App

✓ 手机操作                    [去设置]
```

副标题只在**携带新信息**时才用（例如状态值、当前选择）。
把标题的话换个说法再说一遍，是最常见的一种冗余。

## 二、模块下面不加说明文字

分组的说明、每行下面的解释、功能入口下面的一句"这个功能用来……"——
都去掉。需要解释时用 `InfoTip`（见下）。

列表行右侧的**状态值**（`未设置`、`已关闭`）不是说明，保留。

## 三、免责声明和更新时间只在页脚出现一次

不要在正文中段插一张"数据说明"卡片，也不要每个模块都挂一条。
页脚是唯一位置，且只出现一次。

## 四、按钮写清动作，不写操作指引

```
✗ 点击下方按钮即可开始检查
✓ 开始检查

✗ 请点击此处配置
✓ 去配置
```

按钮上写的是**动词**，不是"告诉你该点它"。

## 五、空状态一句话 + 一个按钮

- 一句话说清"现在没有东西"或"下一步做什么"
- 需要长解释的，放进 `InfoTip` 气泡，**默认不显示**

```
✗ 还没有对话记录
   你和 Maeve 的对话会保存在这里。点击下面的按钮就可以开始第一次对话。

✓ 还没有对话记录                    [开始对话]
```

## `InfoTip` 组件

`ui/components/InfoTip.kt`，两种形态：

```kotlin
// 独立一个问号，气泡在下方展开
InfoTip(text = "设置后 Maeve 才能操作手机 App")

// 行内，接在文字后面
Text("手机操作"); InfoTipInline(text = "...")
```

纪律：**别把主操作依赖的信息藏进气泡**。气泡里放"为什么"，
"怎么做"应该写在按钮上。

## 全量清理记录（第二轮）

第一轮只覆盖设置首页与关于页，第二轮把全项目的 `*_sub` 过了一遍。
判断标准只有一条：**删掉这句，用户还能不能完成任务？**

| 页面 | 处理 |
|---|---|
| 记忆 | 三个开关的说明 → 行尾气泡 |
| 设置 › 做事方式 | 屏幕常亮、静音、允许改设置 → 气泡；并行任务的说明 → 气泡 |
| 设置 › 高级 | 网络代理的复述说明 → 气泡；联网开关的「默认关闭」→ 右侧值，长篇解释 → 气泡 |
| 设置 › 外观 | 配色、跟壁纸、桌面图标三段说明 → 标题旁气泡 |
| 设置 › 开发者选项 | 8 个工程开关的说明 → 气泡；看图定位、运行统计同理 |
| 设置 › 设备访问 / 连接电脑 | 说明 → 气泡 |
| MCP 服务器空状态 | 「还没有 MCP 服务器」+ 副标题 → 一句话 + 「添加」按钮 + 气泡 |
| 运行统计 | 空状态去掉操作指引；导出说明 → 气泡 |
| 自检入口 | 说明 → 气泡 |

**刻意保留的副标题**（它们是状态，不是解释）：

- `未设置`、`已关闭`、`需要处理`、`使用中`、`已就绪` —— 右侧值或状态行
- 开关「关掉后会怎样」在部分位置保留为副标题：只有连状态都说不清时（如
  `wechat_receive_sub = 关闭后不再读取新消息`）
- 并行任务**不支持**时的原因（`p.limit.reason`）—— 灰色行必须当场说清为什么点不了
- 代理**配不上**时的三种提示（只给容器用、浏览器不支持、浏览器用不了 SOCKS 认证）
- 中继/设备访问的安全提示（`Note`）—— 风险告知不属于「说明文字」
- 模型用途单选项的 `roleWhat`、悬浮胶囊模式说明 —— 选它之前必须知道它会做什么
- `PhoneSetupFlow` / `MCP` 的分步引导正文 —— 那是「怎么做」，不是副标题

## `InfoTipInline` 的 overlay 模式

列表行尾（开关、箭头旁边）用 `overlay = true`：

```kotlin
ListRow(...) {
    InfoTipInline(text, overlay = true)
    MaeveSwitch(on, onChange)
}
```

气泡走 `Popup`，**不参与行布局**。若让它内联展开，会把开关挤出屏幕、行高也会跳。
`Popup` 自带「点外面关掉」。

## 已执行的按钮与空状态

- `EmptyNote` 新增可选 `action`：空状态 = 一句话 + 一个按钮，句子后面不再追加「点下面就能…」
- `metrics_empty`：`还没有运行统计。让 Maeve 办件事，这里就会记下。` → `还没有运行记录`
- 按钮文案全部是动词（`去设置`、`开始接入`、`开启网络访问`、`复制`），无操作指引
