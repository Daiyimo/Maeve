# 悬浮胶囊与 Flutter 的共享视觉参数

共享参数在 [`shared/glass_tokens.json`](../../shared/glass_tokens.json) 声明。Kotlin 与 Dart 使用各自编译进应用的参数表。常规 Flutter 测试同时核对两侧，应用运行时不读取共享文件。

## 对齐规则

- 材质层按角色对应。模糊比较密度换算前的逻辑半径，Kotlin 在渲染时按屏幕密度转成物理像素。色洗比较主题和浓度合成前的透明度，底色由各自的主题实现决定。
- 圆角分档比较 Kotlin 的 dp 与 Flutter 的逻辑像素。顶部弹层可以只对顶部圆角，原生悬浮卡可以按停靠方位选择角。全圆角随几何尺寸计算。
- 状态前景色比较 OKLCH 明度、彩度和角度制色相，在两侧各自转 sRGB 之前约定输入。柔和背景和原生无障碍浮层的对比度处理按各自语境确定。
- 时长统一成毫秒。三次贝塞尔控制点按横纵坐标顺序比较。系统减少动态效果由两侧适配器归零。
- Flutter 玻璃可以采样应用内背景。跨应用的 Android 悬浮胶囊用不透明兜底表面，系统不会向它提供其他应用的像素。

## 验收

结构检查由 [`glass_tokens_parity_test.dart`](../../flutter/test/theme/glass_tokens_parity_test.dart) 执行，包含层级、模糊、色洗、圆角、状态色和动效。需要改参数时，在两侧实现与 JSON 中同步变更。

视觉改动用现有 Android 模拟器截图工具人工抽查浅色、深色、胶囊展开和任务完成状态。检查可读性、圆角边缘与过渡，截图不进入 CI 的通过条件。
