## 本批变化

- 正在执行的最新任务采用「实时画面 + 定高执行记录」。新记录从下方出现，旧记录向上滚动；手动翻阅记录时保留位置，点击「回到最新」恢复跟随。历史任务仍可展开完整步骤。
- 外层对话跟随状态由真实滚动手势控制，不再因异步预览图增加页面高度而误判用户在翻历史。自动跟随立即定位；手动回到底部保留动画。停止和完整记录并排，避免挤占画面空间。
- 悬浮胶囊改为不对称书签轮廓、侧边状态刻线、MAEVE 字标及分隔线卡片。标志跟随用户配色，深色浮层以不透明主题底色合成，保留拖动、语音、截屏、输入、停止、确认、接管、历史和缩放功能。
- 应用访问与侧边栏搜索增加填充和可见边框、聚焦状态。顶部标题栏增加不透明底色，连同安全区遮住下层执行记录。
- 首轮尚未落盘时也提供正在执行会话的元数据；开始任务立即用本地短标题占位，模型总结返回后更新标题。
- Amoo 分开显示接入开始、接入验证成功及实际任务结果时间。保存新接入时间，并兼容从现有且匹配当前技能版本的真实标记恢复接入时间；坏标记、其他技能、旧版本不伪造成功。任务结果时间仅取真实结果文件。
