MAEVE · VISUAL SYSTEM · v0.2

纸与机器

整套界面只有两种材质:纸和仪表。你跟 Maeve 说话的地方是温热的纸面——暖白、墨字、一道梅子色; 她在那块你看不见的屏上干活的地方是冷青的诊断台——发丝线、等宽读数、四角校准刻度。 两个世界色相差 140°,所以「谁在说话」一眼可辨,不需要读文字。

界面只装两种字体:系统无衬线说人话,等宽说机器话。字重只用 400 / 500 / 600——AOSP 只带 Noto Sans CJK Regular,w500 会被映射回 Regular、w600+ 走合成加粗,加粗的汉字笔画会糊。

等宽大写微标签是整套设计最省力的记忆点:同一行文案,套上「等宽 + 宽字距 + 小字号」就从正文变成读数,不花一分钱字体授权,不增加一个字节包体。

含中文的微标签自动从 10.5sp 升到 11.5sp——汉字靠笔画密度辨识,10.5sp 时笔锋会糊成一团。

DARK · CANDLELIT

用户的话是梅子色实底气泡,右下角一个 4dp 的尾角——「说出口了」。

她的话不套气泡:左边一条 1dp 发丝轨,文字直接排在纸面上,行高 1.58。气泡是「消息」的语法,她说的是一段念白。

她干活的过程既不是气泡也不是卡片,是一块诊断条:冷青的底、等宽标签、钢琴卷、当前步。这块是全 App 最该有特点的地方——她正在你看不见的屏上动手,所以它必须长得像仪表而不像聊天。

输入栏是全站唯一的玻璃:它是唯一一直浮在滚动内容上的东西,模糊在这里才有理由。形状是圆角 16 的纸条,不是胶囊——胶囊读作「聊天软件」。
