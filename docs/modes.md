# 询问与自主

简体中文 | [English](modes.en.md)

Maeve 替你办事时，有两种模式决定哪些软性限制要先问你。全局一个开关：设置里的「开发者选项」→「自主模式」，关着是询问，打开是自主（默认）。

| 模式 | 行为 |
|---|---|
| **询问** | 对外、不可逆或看不清目标的动作先问你；微信里的每一步写操作也先问。卡片写清在哪、做什么，只能同意这一次或不同意。付款本身由你亲手完成。 |
| **自主**（默认） | 普通可恢复写入继续执行；微信每步写确认与自绘界面盲点点击限制豁免。对外、不可逆、工具申报风险与付款仍然拦下，付款交还用户。成批做事时两次之间的间隔照样保留。 |

- 换了开关管之后的所有任务；正在做的任务从询问换成自主，下一步起只放宽微信每步写确认和自绘界面盲点点击，已经弹出的确认仍要回答。
- 登录、验证码、付款密码这类要你亲手处理的事，两种模式都会请你接管；信息不够、或者只有你能选（比如两个同名联系人选哪个）时，也会问你。
- 定时任务等你不在场的任务，遇到任何需要用户确认的动作都不会等人，会直接不做，并照实告诉你哪一步没做成；别的照常做完。

你同意的动作，以及自主模式下 Maeve 替你做的动作，都由你负责。重要的事请用询问模式，并检查结果，见[免责声明](disclaimer.md)。
