# 视觉契约 — v3「安静的层次」

## 当前修订（2026-11-11）

本节覆盖下方 v2 的同名数值；下方内容保留为设计历史。参考
[dsh-Go](https://github.com/ccch1mneyyy/dsh-Go) 的材质分级与
[desktop-for-step-code 的设计规范](https://github.com/7oMB2006/desktop-for-step-code/blob/main/DESIGN.md)
对中性表面、焦点留白和减少动画的处理，继续使用 Maeve 自己的颜色、组件和资产。

- 画布保持暖侧色相 62，降低彩度：深色 `L .205 / C .0040`，浅色 `L .975 / C .0030`。
  顶/底分别为深 `.218/.200`、浅 `.982/.970`。背景光和暗角大幅减弱。
- 深色 chrome / sheet / card / pill 填充分别为 `L .265/.250/.255/.280`，
  alpha `.82/.96/.72/.66`；边线 alpha 深/浅均为 `.075`。
- card / pill 使用哑光填充，无顶边高光、无 sheen、无投影；chrome / sheet 保留有界模糊。
  页面顶栏和侧栏使用 `framed: false`，不再有环绕描边、sheen 或外投影。
- 首屏收在 480dp 阅读列内，标志、标题、说明、三个示例共享左侧基线；保留滚动以适应小屏和大字。
- 输入栏分为文本与动作两行，最小高度 104dp，外部预留完整 4dp 焦点边缘；多行输入与键盘场景均有回归覆盖。
- 标题逐帧更新，按完整字素显示；读屏只播报一次完整标题。减少动画可在入场中途立即结束打字效果。
- 测试使用固定会话日期、显式手机视口、假宿主与通道清理；持续动画通过有界推进验证。
  CI 自动执行 Flutter、JVM 和 Android 单测，保存测试报告，不通过忽略失败或自动重试掩盖问题。

## 0. 诊断:原型为什么"不好看"

| 症状 | 真因 | 这次怎么改 |
|---|---|---|
| 整屏灰紫、发脏 | 画布色相 250(冷)+ 强调色暖(348)→ 互相抵消 | 画布色相固定 **62**(暖),彩度 1.6%;强调色一族挪到 312(兰紫) |
| 卡片没有边界,像水渍 | 深色下填充是"白 6%"、描边是"墨 9.5%" —— 两者都太淡 | 深色玻璃改用**同色相的暖灰填充**(不走白灰),描边抬到墨 15% |
| 玻璃像灰色塑料 | 只有"半透明 + 一圈描边",没有方向感 | 新增 **sheen**:玻璃内部自上而下的一道提亮 |
| 背景像一块脏印子 | 只有三团极光,没有光源也没有暗角 | 新增 **光源 bloom** + **四角暗角 vignette**,极光半径收小 |
| 说明字看不清 | `ink3` 只做到 3:1(设计下限),12px 直接糊 | `ink3` 抬到 **5.5:1**,行高全部改 `leadingDistribution.even` |
| 一屏三个色相 | 设置分组按"能力=绿、外观=梅子"上色 | 分录不再上色;颜色只留给真正表示状态的 chip |
| 顶栏一团灰字 | 眉标 + 标题 + 副标题三行叠在 56 里 | 顶栏只说两件事:标题 + 一行状态(点 + 一句话) |
| 首屏中间空半屏 | 空状态贴着顶栏排 | 空状态**垂直居中**,示例从三个盒子收成一张卡 |

## 1. 定位与竞品对照

Maeve 不是开发者工具,是**替你把手机上的杂事办完的人**;情绪承诺是"你的屏幕还是你的"。
所以视觉要像**一间关了灯、只开一盏灯的屋子**,不是仪表盘,也不是 IDE。

| 项目 | 它的色彩/材质决策 | Maeve 怎么选 |
|---|---|---|
| dsh-Go(Mist Glass) | 冷蓝灰画布(#EBF1FE / #1D222C),强调色固定 267°,四档玻璃 + OKLCH 推导,70/25/5 配比 | **同一套推导纪律**,但画布换暖侧、强调色换 312°:同一门语言,不同口音 |
| desktop-for-step-code | 平铺、1px 描边、小圆角(3–8)、Segoe UI、14px 密排 —— 明确的"工具感" | 保留玻璃与较大圆角(20/28)与更松的行高:它读作"工具",Maeve 要读作"陪伴" |
| Maeve | — | **暖画布 + 兰紫强调 + 被上光照到的玻璃** |

结论:两家竞品都不在"暖",这就是 Maeve 的位置。

## 2. 颜色

六条规矩:

1. **一个彩色。** 全站只有 `accent` 一族有彩度。状态色只在真正表示状态处出现,
   且永远配文字或图形,不靠色相大面积铺开。
2. **画布是暖的。** `neutralHue = 62` 固定,不随强调色转;彩度极低(深 1.6% / 浅 0.9%)。
   冷色强调(珍珠、夜靛)落在这张暖画布上会变成"暖暗部 + 冷高光"的电影调色关系。
3. **表面阶梯是"被照亮的程度"**,相邻档差 2–3 个明度点;边界由发丝线承担。
4. **文字四级暖灰**,全部从画布按明度阶梯推,`ink2`/`ink3` 过 `guard()`。
5. **投影是暖的**(浅色下 `floatShadow = #3A2E24`)。中性灰阴影压在奶色纸上会发蓝。
6. **光是真的光**:`sheen` 提亮玻璃、`bloom` 是唯一光源、`vignette` 压暗四角。

### 2.1 画布与文字(OKLCH,色相恒 62)

| 令牌 | 深色 | 浅色 |
|---|---|---|
| `bg` | `L .190 / C .0160` | `L .960 / C .0090` |
| `bgTop` / `bgBottom` | `.202/.0172` · `.174/.0150` | `.972/.0082` · `.946/.0100` |
| `ink` | `.966 / .0050` | `.205 / .0130` |
| `ink2`(≥4.5) | `.780 / .0072` | `.450 / .0115` |
| `ink3`(≥3,实测 5.5/4.4) | `.640 / .0086` | `.555 / .0105` |
| `ink4`(≥2.2) | `.505 / .0098` | `.700 / .0090` |

### 2.2 状态色(色相固定,与强调色无关)

| 语义 | 色相 | 深色 | 浅色 |
|---|---|---|---|
| ok | 150 | `L .780 / C .075` | `L .455 / C .105` |
| warn | 78 | `L .800 / C .112` | `L .470 / C .105` |
| bad | 22 | `L .700 / C .145` | `L .470 / C .145` |
| info | 248 | `L .790 / C .098` | `L .455 / C .105` |

> `warn` 从 70 挪到 78、`bad` 从 25 挪到 22:画布是 62,警告色必须离画布色相足够远,
> 否则金色会被读成"背景的一部分"。

## 3. 六套预设

种子色(浅色种子配白字 ≥4.5;深色种子是"光",明度 .78–.87):

| id | 名 | 浅色种子 | 深色种子 | 彩度倍率 |
|---|---|---|---|---|
| `reverie`(默认) | 梅子 | `#7D499A` | `#CDABE3` | 1 |
| `dolores` | 黄铜 | `#865C17` | `#E9BC7A` | .85 |
| `maze` | 沙原 | `#775D4A` | `#D5B7A1` | .9 |
| `pearl` | 珍珠 | `#50666F` | `#B0CAD2` | .7 |
| `sublime` | 夜靛 | `#3F5598` | `#9BB4F5` | .9 |
| `graphite` | 石墨 | `#2E2B28` | `#D7D3D1` | .15 |

推导阶梯(`_spec()`,深色):seed → pressed `L−.06`、onSeed `.231 ×.39C`、
container `.361 ×.51C`、glow `.580 ×.72C`、haze `色相+24° / L .50`。彩度上限 `.135`。

**梅子为什么从 348 挪到 312:** 348 与失败色 22 只差 34°,一个小圆点到底是"强调"还是
"出错"只能靠猜。312 离红 70°、离琥珀 126°、离成功绿 162°。

## 4. 表面:四档玻璃

| 档 | 用在哪 | 深色填充 | 浅色填充 | 模糊 σ / 饱和 |
|---|---|---|---|---|
| `chrome` | 顶栏、输入条 | `_n(.310,.0125)` α.62 | 白 α.74 | 24 / 1.40 |
| `sheet` | 弹层、抽屉、面板 | `_n(.335,.0130)` α.72 | 白 α.88 | 30 / 1.55 |
| `card` | 设置卡、任务卡 | `_n(.270,.0115)` α.50 | 白 α.68 | — |
| `pill` | 胶囊、标签 | `_n(.290,.0120)` α.56 | 白 α.78 | — |

每档另有:`hairline`(深 墨 α.15 / 浅 墨 α.13)、`rim` 顶边高光(深 白 α.24 / 浅 白 α.98,
占高度 `.18–.50`)、`sheen`(深 白 α.065 / 浅 白 α.60,收到透明的比例 `.34–.62`)、
以及**只画在形状外部**的暖投影。

- **深色不用"白 + 低透明"**:白会把底色的暖冲掉,一屏玻璃全变冷灰。
  用同色相的暖灰做填充,彩度才能保住。
- `blurEnabled = false` 时四档走 `fallbackFill`(合成到不透明)且**不建**
  `BackdropFilter`;高对比度模式同样降级。
- 平放的 `card` / `pill` **不取样**(否则玻璃里套玻璃);`chrome` / `sheet` 才真模糊。

## 5. 背景:四层,顺序不能换

1. **竖渐变** `bgTop → bg → bgBottom`(stops `0 / .52 / 1`)
2. **极光** 三团:主色左上(r = .92·short)、邻近色右侧(.70)、冷色底部(.90)
3. **光源** `bloom`:右上、r = .38·short、彩度只有强调色的 1/3(深 α.18 / 浅 α.20)
4. **暗角** `vignette`:从中心到对角,只压最外 42%(深 黑 α.42 / 浅 暖褐 α.16)

浅色下极光必须非常淡(α .11/.08/.05):奶色纸上一点带色光的雾,整屏立刻读作"粉紫"。

## 6. 字阶

两种字体(系统无衬线 / 系统等宽),三种声部:等宽微标签、等宽读数、无衬线正文。
全部 `leadingDistribution: even`(中文字形没有降部,默认比例分布会让中文行偏上)。
字重只用 400/500/600。**大号展示字不用 Bold 合成**(中文合成加粗会糊)。

| 样式 | 字号 / 行高 | 字重 / 字距 |
|---|---|---|
| `display` | 33 / 38 | 500 / −.9 |
| `largeTitle` | 26 / 32 | 500 / −.6 |
| `title`(顶栏) | 16.5 / 22 | 500 / −.2 |
| `body` / `bodyStrong` | 15.5 / 24 | 400 / 500 |
| `script`(她的回答) | 16 / 27 | 400 / −.05 |
| `caption` | 13.5 / 20 | 400 |
| `label`(分组标题) | 12.5 / 18 | 500 / +.1 |
| `hint` | 12 / 17 | 400 |
| `eyebrow`(等宽读数) | 10.5 / 14 | 500 / +.7(中文 11.5 / +.2) |

**等宽微标签是签名,不是背景音**:一屏最多一处。顶栏只留标题 + 一行状态;
分组标题用无衬线的 `label`。

## 8. 验收

- 六套预设 × 明暗:文字 ≥4.5、非文本 ≥3、强调色对画布 ≥3、强调色上的字 ≥4.5;
  `flutter test test/theme` 逐项算,不靠眼。
- 换预设时各级文字对比度**完全不变**(中性色相/彩度固定)。
- 玻璃上的字仍然可读(填充合成到画布之后 ≥4.5)。
- `blurEnabled=false`:无 `BackdropFilter`、四档填充接近不透明。
- 减少动效:所有时长归零、按压不缩放、循环停静止帧。
- 不复制 dsh-Go 的任何源码、字符串、drawable、字体或色值(只参考推导规则)。
