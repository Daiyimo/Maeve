# Maeve 视觉语言 v7 · 紫色日食与紧凑会话

2026-11-12。Flutter 是唯一应用界面；Android 保留能力与平台服务。

## 品牌

默认「觉醒紫」：浅色种子 #7651C7，深色种子 #CBB7FF。以《西部世界》中 Maeve 的深紫丝绒、清醒、选择与对具体人的关切为叙事灵感。品牌文案「下一幕，由你决定」，关于页解释名字来由。人物叙事由项目资料提炼，文案为本项目原创。

品牌标采用用户选定的「01 平衡静态 + 02 偏离执行态」。以原生版日食环为起点，借鉴 Rehoboam 的日冕与局部偏离视觉，保留紫色和空心圆核；轮廓、微刻痕与稀疏颗粒由本项目矢量几何绘制，不使用剧集截图或生成位图。`MaeveEmblem` 直接呈现空心日食，撤掉珍珠底座。

静态轮廓、刻痕与启动图来自 `flutter/lib/widgets/eclipse_geometry.dart`。`dart run tool/export_eclipse_icons.dart` 导出 Android 前景与单色向量，CI 用 `--check` 防止启动图和界面 Logo 分叉。小于 28dp 的标记简化刻痕，小于 56dp 不画离散颗粒，保持细线清晰。

顶栏与过程提示仅在真实对话事件的 busy 状态进入 02；完成后回到 01。执行态只改变局部径向扰动，不旋转整圈；重绘隔离在 Logo 的绘制边界内，不重建页面。静态没有持续 ticker；系统减少动效、页面不可见时冻结执行态，仍保留状态文字。

参考 [Desktop for Step Code](https://github.com/7oMB2006/desktop-for-step-code) 的内容层级、焦点完整性与减少动效约定，结合 iOS 玻璃的透色和边缘光感，重新实现手机端布局；不复制其布局、logo、代码或资产。

## 色彩

六套完整氛围：觉醒紫、丝绒红、雾松、冰川、暮光、月白。稳定 ID 保留，背景、文字温度、强调色与玻璃共同变化。OKLCH 推导与守卫位于 `flutter/lib/design/maeve_accent.dart` 和 `flutter/lib/design/maeve_colors.dart`。所有配色均有浅深两种模式；语义状态色独立于装饰色。

正文、次级和辅助文字对各自画布至少 4.5:1；主按钮文字至少 4.5:1。玻璃对比度按透明层压在画布后的实际颜色计算。色彩不是状态唯一线索，状态保留文字和图形。

## 玻璃

`MaeveGlassSurface` 是唯一材质入口：有界模糊、饱和度、透明填充、方向性 sheen、顶边高光、外部投影。四档为 chrome / sheet / card / pill；只有前两档默认真实采样，列表卡片以静态光学层次避免反复模糊。首页只采样顶栏与输入栏两层；Logo 无模糊；设置首屏仅顶栏一层。顶栏合并采样。真机发现列表卡片额外采样会出现水平条纹，因此设置概览的列表卡片仅使用静态光学层次，禁止在已模糊的弹层内再对卡片采样。

静态光源来自背景的主题光晕。交互时，`Pressable` 按触点位置出现径向流光并按压回弹；日食标有有限入场动画，抽屉跟手移动后落位，弹层落位后透出玻璃。没有空闲装饰循环。

材质层次以背景、卡片、浮层递进。无框顶栏降低填充，减少整条灰色面板的割裂；透明降级仍用原不透明回退。顶边高光按色位原有 alpha 再衰减，避免用 `withValues(alpha: ...)` 意外把微弱高光变成强白边。卡片高光最弱，浮层保留较强边光；布局、六套配色与文字对比度约束不变。

减少透明效果或高对比度时不创建 `BackdropFilter`，使用合成后的不透明填充；减少动效时不缩放、入场立即完成。这里是 Flutter 绘制的玻璃视觉，不依赖原生 iOS 材质或系统折射 API。

## 布局与字阶

手机内容保留 16–24dp 水平留白；主页按顶栏与输入区之间的真实剩余高度排版，三枚轻入口在下方，中部保留呼吸空间。正常 320×568、369×822、412×915 首屏不滚动，大字与键盘场景允许滚动以保持可达。主视觉居中，列表共享左基线。正文最大阅读宽度由 `MaeveSpace.readingWidth` 控制；系统安全区、键盘和大字场景均需可滚动。

设置分组间隔 32dp、组标题下 12dp；触控行最小高度 48dp，顶栏动作 48dp；设置分段按钮至少 44dp。行尾值按行的实际宽度限制，不能按整屏宽度挤压标题。色彩快捷入口每项至少 44dp 宽，配色详情展示名字和气质，不向用户暴露十六进制参数。

大字只用 400 / 500 / 600 三档字重，品牌标题 29dp，设置页标题与状态单独排版。正文与代码使用系统无衬线和等宽回退，中文优先。

会话抽屉采用独立的干净表面，浅色以白色与极弱主题色合成，不采样已被遮罩压暗的对话。标题单行 14sp、行最小 44dp，随系统大字自然增高；头部文字 15sp。普通手机首屏可显示至少十条会话。工作台与右侧抽屉移除，设置保留在左侧抽屉底部。

执行过程以原生步骤、动作结果和失败说明为内容；实时画面有界缩略、可点按放大。历史画面与步骤来自本机运行记录，状态文字区分执行、失败、停止和等待确认，不用统一的完成样式覆盖真实结局。

`flutter/test/ui/layout_audit_test.dart` 覆盖全部 10 个实际 Flutter 设置页面，在 320×568、412×915（1.6 倍字）、768×1024 下检查顶部与底部排版异常。另有真实聊天事件、发送/停止、引用、会话、抽屉、权限确认、键盘和配色对比度测试。

`flutter/tool/preview_test.dart` 使用本地 CJK 字体生成深浅页面、全部配色和长页面末尾截图，供人工逐屏检查。输出只在 build 目录；不把环境字体或截图金样作为 CI 依赖。
