# Maeve v0.1.0 — Dolores

状态：发布候选（staged），尚未发布到 GitHub Release ｜ 准备日期：2026-11-27 ｜ 构建编号：见下方「构建信息」｜ Beta

首个完整发布签名候选版本；仓库保存发布说明与校验值，APK 资产需在正式发布时上传。本版本补齐 Amoo 自动签到、视觉优先、非支付自主执行、微信 Amoo 后台执行、任务分享导出与隐私声明，并修复定时任务在 Doze、锁屏和系统限制下的补跑问题。

## 这个版本改了什么

### Amoo 自动签到与定时任务
- 内置每天 09:00（Asia/Shanghai）的 Amoo 成长计划签到实例，首装默认停用，用户启用后自动打开所属会话。
- 亮屏、网络恢复或应用回到前台时直接补跑到期任务，不再等待可能被 Doze 推迟的第二次闹钟。
- 锁屏或系统禁止前台服务启动时保留任务并等待恢复；同一到期时间不重复取消重排。
- 定时任务上下文隔离，修复真机测试 Fixture；Android 11 助手交接兼容反射签名。

### 视觉优先与连续自主执行
- 普通已识别应用默认视觉优先，视觉失败不回退 UI 树；StepX/Amoo 保留视觉→UI 兜底。
- 非支付动作连续执行，只有真实支付、登录/验证码、系统授权等关键场景才请求用户接管。
- 动作效果闭环区分 Applied、NotApplied 与 Unknown；`phone_tap` 增加 10 秒上限，取消后仍保留投递回执，避免 `effect_unknown` 停摆。

### 微信 Amoo 后台执行
- 微信消息可转交系统 Amoo，并在 Maeve 中显示后台进度、网络状态与完成回复。
- 新增网络恢复监听、前台通知、邮箱文件原子写入、回复稳定判定与二维码本机编码。
- 解绑、停止执行和取消登录分别处理，避免后台任务与聊天状态互相干扰。

### 任务报告、回放与分享
- 任务报告展示目标、结论、来源、耗时与操作回放；回放按调用发生顺序排列。
- 分享图左侧展示精简回答，优先完整保留实际体验码；支持选择回放帧。
- 分享图提供编辑、下载、分享三个入口：下载保存到 `Download/Maeve`，分享拉起系统面板。

### 隐私、安全与网页
- 新增独立隐私声明页，说明对话、屏幕内容与截图的数据去向、本机保存和第三方通道例外。
- 支付、登录/验证码、Android 运行时权限与系统授权仍按来源拒绝或请求确认。
- 网页回归覆盖桌面/手机 UA、DevTools 会话、点击输入、网络等待与 `X-Requested-With` 请求头。

### 发布工程化
- Release 构建必须配置发布密钥，缺失时直接失败，避免产出不可验证或无法覆盖升级的包。
- 版本号保持 `0.1.0`，代号 Dolores 只写在发布说明中，避免预发布号导致更新与安装冲突。
- 本地 Flutter AAR 仓库优先于公网仓库，离线环境可复用已构建 AAR。

## 安装

两个包代码、资源、版本号、签名完全一致，只差 `lib/` 下的其他架构原生库，各自都是完整 APK。

| 附件 | 适用 | 大小 |
|---|---|---|
| `Maeve-v0.1.0-arm64.apk` | 支持 arm64-v8a 的设备（绝大多数现代手机，更小） | 89.9 MB |
| `Maeve-v0.1.0.apk` | 全架构，其他设备用这个 | 119.3 MB |

App 内「获取更新」会按本机 ABI 自动挑：支持 arm64-v8a 就取 `-arm64.apk`，否则取全架构包。

要求 Android 11（API 30）及以上。只聊天、上网、处理文件不需要无障碍；要操作手机 App 才需要按[设置指南](../docs/setup-guide.md)开启无障碍与手机助手。

## 校验

下载后可核对 SHA-256（与 `SHA256SUMS.txt` 一致）：

```
dfd12429dcfc4d89ae74696fa43ed2b5d5938b42fafe0ee5ff09c256cf67930d  Maeve-v0.1.0.apk
47f06654c2639a0cb6b3a85428c7b306469a3743f075dff666921e652dc3f012  Maeve-v0.1.0-arm64.apk
```

发布签名证书 SHA-256 指纹（`keytool -list -v` 或 `apksigner verify --print-certs` 可核对）：

```
B4:70:95:9A:BA:88:83:A1:7C:A5:64:47:7B:76:4E:86:39:A2:38:11:CA:8F:B7:B9:34:02:FD:AA:BD:AE:63:58
```

**这是第一个用正式密钥签名的版本。** 此前装过调试签名包的设备无法覆盖升级，需要先卸载再装（会丢失本地对话与授权，卸载前请自行导出需要保留的内容）。从此往后的版本都用同一把密钥，可正常覆盖升级。
