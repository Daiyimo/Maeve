# Maeve v0.1.0 — Dolores

发布日期：2026-11-17 ｜ 构建编号：见下方「构建信息」｜ Beta

首个带完整发布签名的版本。本版本把悬浮胶囊、触感反馈、任务过程可视化与「获取更新」四条体验补齐，
并修掉了上一次提交遗留的测试基准错位。

## 这个版本改了什么

### 悬浮胶囊视觉再打磨
统一强调色与玻璃层级，胶囊在任意背景上都保持同一套明暗关系；主题色改用更贴气质的一组命名
（reverie / dolores / maze / pearl / sublime / graphite）。

### 触感反馈修复
此前开关打开也不震动。根因是触感调用没有落到原生引擎上。现在五级触感
（tick / light / medium / heavy / reject）统一经 `maeve/ui` 桥走到原生 `MaeveHaptics`；
退页与收弹层由路由的 `PopScope` 发反馈，不再依赖各页面自己记得调。
按钮点击、开关切换、返回、弹层收起都有对应震感。

### 任务报告与操作回放
移植 Mika 的「查看过程 / 任务报告 / 操作回放」三件套，重做成 Maeve 的玻璃语言：
- **查看过程**：按步展开工具调用、观察与结果，截图可点开细看
- **任务报告**：目标、结论、来源与耗时汇总，可导出为文件（走系统 `ACTION_CREATE_DOCUMENT`）
- **操作回放**：按记录的动作序列重演，每一步带当时的画面

### 内置「获取更新」
对齐 Mika 的检查 / 下载 / 安装闭环：只查本仓库的 `releases/latest` 接口，
下载交给系统 DownloadManager，安装前依次校验 SHA-256、包名、版本号与签名证书，
任一项不通过就删掉文件并说明原因。取消与页面退出都会中止正在进行的下载。

### 测试基准修正
上一次提交把 16 份对话金样与提示词体积基准按「另一版提示词」写死，比实际提交的版本长 178 字节，
导致 19 个用例长期红着。本版本按真实提示词重算金样，并把 Anthropic 的上下文压缩触发点
改回实测的 `[12, 22]`。提示词内容本身未改动 —— 那段「对外动作需单次本地确认、自主模式不豁免、
付款交用户、远端回答不算本地批准」的安全约束完整保留。

### 发布工程化
- 补齐 release 签名配置（`SPEC.md` §8.6 的待办项）。密钥不进仓库，按
  `local.properties` → 环境变量的顺序读；两处都没有时退回调试签名并打印警告，
  保证 CI 与干净 clone 仍能构建。配置方式见 `local.properties.example`。
- 本地 Flutter AAR 仓库提到公网仓库之前。此前 `mavenCentral()` 在前，而这个模块是本项目自产、
  只存在于本地，公网 DNS 不通时会直接中断解析，让明明躺在本地的模块解析失败。
- 版本号去掉代号后缀。`0.1.0-dolores` 会被 `AppVersion` 判为预发布版，
  而发布 tag `v0.1.0` 是正式版 —— 装了本版本的人会被提示「升级到 0.1.0」，
  点安装又因 versionCode 相同被系统拒绝。代号 Dolores 只写在发布说明里。

## 安装

两个包代码、资源、版本号、签名完全一致，只差 `lib/` 下的其他架构原生库，各自都是完整 APK。

| 附件 | 适用 | 大小 |
|---|---|---|
| `Maeve-v0.1.0-arm64.apk` | 支持 arm64-v8a 的设备（绝大多数现代手机，更小） | 84.5 MB |
| `Maeve-v0.1.0.apk` | 全架构，其他设备用这个 | 111.8 MB |

App 内「获取更新」会按本机 ABI 自动挑：支持 arm64-v8a 就取 `-arm64.apk`，否则取全架构包。

要求 Android 11（API 30）及以上。只聊天、上网、处理文件不需要无障碍；
要操作手机 App 才需要按[设置指南](../docs/setup-guide.md)开启无障碍与手机助手。

## 校验

下载后可核对 SHA-256（与 `SHA256SUMS.txt` 一致）：

```
f4337069cf56d23ac1621f2c5c1643bb017aa658da5145e35aa7f0f9441e71f2  Maeve-v0.1.0.apk
a55fa7c9bae83c75f65296535fafd2167e555698f261e1e45d017f0fc1288021  Maeve-v0.1.0-arm64.apk
```

发布签名证书 SHA-256 指纹（`keytool -list -v` 或 `apksigner verify --print-certs` 可核对）：

```
B4:70:95:9A:BA:88:83:A1:7C:A5:64:47:7B:76:4E:86:39:A2:38:11:CA:8F:B7:B9:34:02:FD:AA:BD:AE:63:58
```

**这是第一个用正式密钥签名的版本。** 此前装过调试签名包的设备无法覆盖升级，
需要先卸载再装（会丢失本地对话与授权，卸载前请自行导出需要保留的内容）。
从此往后的版本都用同一把密钥，可正常覆盖升级。

## 已知限制

- 仍是 Beta。沙箱、Root、出站 Relay、外部 MCP server、语音、微信、无障碍截获默认不启用。
- 未开启 R8（`minifyEnabled`）与资源压缩，包体偏大。
- Windows 上 `:core:test` 有 32 个沙箱/工作区用例因缺少符号链接权限失败，属环境限制，非代码缺陷。
